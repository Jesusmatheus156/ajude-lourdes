# Ajude Lourdes — GitHub Pages

## Publicar
1. Crie um repositório no GitHub, por exemplo `ajude-lourdes`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve.

## Antes de publicar
Abra `script.js` e substitua:
- COLE_AQUI_O_LINK_DO_VIDEO_DO_INSTAGRAM
- COLE_AQUI_O_LINK_DO_INSTAGRAM
- COLE_AQUI_O_LINK_DO_TIKTOK
- COLE_AQUI_O_LINK_DO_KWAI

O Pix já está configurado como 124.638.074-90.

## Importante
Teste o QR Code e a chave Pix em mais de um celular/banco antes de divulgar em massa.
